# Resumen del proyecto — xTechJS

**xTechJS** es una aplicación web completa para la gestión integral de un laboratorio técnico de reparación especializado en:

- Consolas de videojuegos (actuales y retro)
- Dispositivos móviles (smartphones y tablets)
- Pequeño electrodoméstico

La aplicación debe cubrir todo el ciclo de vida del negocio: captación y gestión de clientes (CRM), gestión operativa de las reparaciones (equipos en taller), cobros (TPV), y control de almacén/stock de componentes y repuestos.

El objetivo de este contexto es que sirva de especificación funcional y técnica completa para el diseño e implementación de la aplicación.
